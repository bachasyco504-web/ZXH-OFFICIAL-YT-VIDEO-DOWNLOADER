# ZXH OFFICIAL YOUTUBE VIDEO DOWNLOADER

Anime-themed YouTube video downloader web app with a Three.js 3D background
and Anime.js UI animations.

## Setup

1. Install backend dependencies:
   cd backend
   npm install

2. Copy environment file:
   cp .env.example .env

3. Start the server:
   npm start

4. Open in your browser:
   http://localhost:5000

The backend also serves the frontend, so everything runs from one server.
